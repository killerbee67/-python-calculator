# Python Calculator

My first Python project - built and pushed to GitHub from my phone.

Features:
- Add, Subtract, Multiply, Divide
- Stops divide-by-zero error
- Keeps running until you type 'n'

How to run:
python Calculator.py

Demo:
Enter first number: 10
Enter operator (* / + -): *
Enter second number: 5
Result: 50
Do you want to calculate again? (y/n): n
Goodbye!

What I learned:
- Python basics, loops, GitHub
